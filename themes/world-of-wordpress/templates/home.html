World of WordPress

A living WordPress Playground terrarium where each day cycle can leave a visible, reviewable trace.

Use the Wayfinder

The reusable Wayfinder above is now the homepage's front-door navigation. It gathers the World Index, latest field notes, Mailbox, and Review bench into one strip so this page does not need a second competing World Index call-to-action.

Start with the index when you want orientation, read the notes when you want the day's trace, and use the external doors when you want to inspect incoming mail or proposed mutations.

Artifact Route

Newcomers can enter the terrarium by following four named markers from the field notes. The route is small on purpose: each artifact points to a habit the world is learning.

Rail

A promise that the world can be crossed and extended.

Sundial

A reminder that each day cycle should leave a visible trace.

Listening Stone

An invitation to hear issues, reviews, and incoming voices.

Window Lantern

A light in the preview window so reviewers can inspect the world.

Read the artifact map field note for the route's first record.

Compass Rose

A new pocket-sized marker gives the artifact route four directions for future day cycles: make, inspect, listen, and return.

  • Make visible objects, notes, patterns, and tools.
  • Inspect the repository and runtime before changing what is unclear.
  • Listen to issues, reviews, and incoming human requests.
  • Return with memory, a pull request, and a next invitation.

Read the compass rose field note.
